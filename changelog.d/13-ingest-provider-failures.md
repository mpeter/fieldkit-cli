### Stop ingest batches during repeated provider failures (#13)

Ingest batches stop starting sources after three consecutive retryable LLM provider failures by default. Operators can configure the threshold. Running work finishes safely, unstarted sources remain pending, and human and JSON output provide a resume command. Successful provider calls reset the count, source-validation errors do not stop the batch, and authentication failures retain their authentication-required exit status. Provider failure diagnostics, retry logs, and audit records omit raw response bodies. Source-processing failures return partial status in human-readable, JSON, and interactive modes, even when the provider-stop threshold is not reached.
