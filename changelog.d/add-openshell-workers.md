### Add opt-in OpenShell task workers

Developers can run explicit bounded commands over committed source snapshots in
disposable OpenShell workspaces and review returned artifacts. A shared tools-only
devcontainer image supplies locked development dependencies without coding-agent
CLIs or a model framework. Project policies and explicitly selected providers own
network access; model tasks and credential adapters remain project integrations.
This preview path targets Linux amd64 with rootless Podman and OpenShell 0.1.2.
