# Enterprise data capabilities

Rover organization data, authenticated Jira data, or Snowflake analytics may be
available through a configured authorized enterprise MCP route. Inspect the active
harness configuration and the tools actually exposed; neither a fixed group name
nor any particular data source is guaranteed.

Confirm the requested data source, read/write scope, approved identity, and required
network or authentication dependency before use. If the selected capability is
unavailable, name the missing dependency. Do not invent a separate group, borrow
another workspace's route, or treat browser access as structured API parity.
