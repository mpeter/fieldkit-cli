# Web research boundary

fieldkit does not install or require a web-search provider. Use a browser or
search tool only when it is available in the current environment and the user has
not prohibited network access. Inspect the selected tool's current interface
instead of assuming a maintainer-specific executable or plugin.

Define whether the task needs search snippets, a primary source, extraction from
one known page, a bounded site crawl, or comparison across sources. Prefer
official and primary sources for technical behavior. Record URLs, publication or
revision dates, and the date accessed when freshness matters.

Different indexes and authenticated sites have different coverage. Identify a
second provider as an independent source, not a transparent fallback. A failed
or unavailable provider does not prove that no source exists. Keep incomplete
research pending and distinguish observed facts from inference.

Never paste credentials, customer text, private URLs, or sensitive query terms
into a public search service without explicit authorization for that disclosure.
