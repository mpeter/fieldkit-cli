# Memory Management

Memory makes Claude your workplace collaborator — someone who speaks your internal language.

## Gotchas

- **Stale vault signals** — run `/brief` first if data hasn't been refreshed today
- **Trigger overlap with adjacent skills** — confirm you need this skill and not a closely named one

## Constraints

- **Never write to account files without explicit confirmation**
- **Always surface generated output for review before any external send**

## The Goal

Transform shorthand into understanding:

- "ask todd to do the PSR for oracle" → fully decoded with names, roles, deal context.

## Architecture

```
CLAUDE.md                                          ← Hot cache (~30 people, common terms)
<fieldkit_home>/memory/
  system/                                          ← Committed, shared knowledge
    lessons-learned.md                             ← Lessons from wins, losses, key interactions
    sf-org-security-limitations.md                 ← SF org policy notes
  personal/                                        ← Gitignored, user-specific
    contacts/
      contact_<name>_<account>.md                  ← Generated by the contact skill's contact-enrich pipeline
```

## Lookup Flow

1. Check CLAUDE.md (hot cache) — covers 90% of daily decoding
2. Search `<fieldkit_home>/memory/system/lessons-learned.md` — historical context and learned patterns
3. Search `<fieldkit_home>/accounts/<account>/gmail-intel.md` — email engagement signals
4. Ask user — unknown term? Learn it.

## Adding Memory

- **Lessons learned** → `<fieldkit_home>/memory/system/lessons-learned.md` (dated entries with account/topic)
- **Preferences** → CLAUDE.md Preferences section
- **Contact files** → auto-generated by the `contact` skill's `src/fieldkit/skills/contact/ops/contact-enrich.md` pipeline into `<fieldkit_home>/memory/personal/contacts/`

## Promotion / Demotion

- **Promote** to CLAUDE.md when frequently used or part of active work
- **Demote** to `<fieldkit_home>/memory/system/` only when stale (project done, person no longer frequent)
