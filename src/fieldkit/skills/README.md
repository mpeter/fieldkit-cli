## Contributing

Keep one skill per subdirectory with a `SKILL.md` entry point. Supporting
references and templates live beside their owning skill. Update this index when
adding, renaming, or removing an entry point; do not copy skill descriptions here.

Discovery does not prove that an integration is configured or that a workflow has
been verified. Read the selected skill's prerequisites before invoking external
services or allowing writes.
