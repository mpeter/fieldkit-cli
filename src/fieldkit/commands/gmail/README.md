# Gmail commands

For authentication, configured storage, sync modes, querying, and recovery, use
the current [Gmail guide](https://github.com/mpeter/fieldkit-cli/blob/main/docs/guides/gmail.md).
The [CLI reference](https://github.com/mpeter/fieldkit-cli/blob/main/docs/cli-reference.md)
lists the supported commands and options. These public links also work from an
installed package, which does not include the repository's `docs/` directory.
